# Iterasi-Gauss-Seidel-pada-Sistem-Linear-4-Variabel-
Implementasi Metode Gauss-Seidel untuk menyelesaikan Sistem Persamaan Linear (SPL) 4 variabel secara iteratif hingga konvergen dengan batas error tertentu. Proses melibatkan perhitungan error relatif antar iterasi untuk mendapatkan solusi yang stabil dan akurat.
